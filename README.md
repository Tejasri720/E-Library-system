# 📚 E-Library Management System

A responsive Digital Library Management System developed using React.js. It allows users to browse books, search by title or author, filter by category, manage favourites, and view book details. It also includes an Admin Dashboard for managing books, registered users, and contact messages.

## 🌐 Live Demo

[Visit E-Library Management System](https://e-library-management-system-one.vercel.app/)

## ✨ Features

### User Features
- User Registration and Login
- Browse available books
- Search books by title and author
- Filter books by category
- View detailed book information
- Add and remove books from favourites
- View recently viewed books
- Responsive user interface

### Authentication
- User login and registration
- Protected routes using React Router DOM
- Login required for selected features
- Redirect users to their requested page after login

### Admin Features
- Admin Dashboard
- Add new books
- Edit existing book details
- Delete books
- View registered users
- Manage contact messages

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd E-Library-Management-System
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:5173/
```

## 🔄 Application Workflow

1. Visitors can access the Home page.
2. Users can browse, search, and filter available books.
3. Users must log in to access protected features.
4. After successful login, users are redirected to their requested page.
5. Logged-in users can manage favourites and recently viewed books.
6. Administrators can manage books, users, and contact messages through the Admin Dashboard.
